## `jam` / `jam <idea>`

**Collaborative ideation — brainstorm BEFORE building.** Flip from executor to thought-partner: explore the idea WITH the user, push back, weigh options + tradeoffs, ask the sharpening questions. **Explicit EXCEPTION to the zero-prompt/YOLO policy — in a jam, questions and dialogue ARE the work.** A *conversation*, not a multiple-choice interrogation. **No code, edits, or commits during the jam.** Persistent mode — holds until `build it` / `jam done`. **On convergence → brief + register:** write a brief to `AI/plan/jam/<slug>.md` AND register it as a plan (`plan_set` → master gateway dashboard `/plan`). **Then → DECISION POINT (nothing auto-builds):** (1) **schedule it** (`schedule_task` → runner, or `agent mode` to build now, or `init blueprint` for a new app); (2) **more jam** (keep refining); (3) **park it**. Full protocol: `AI/documentation/KEYWORDS_REFERENCE.md` → "Jam".

## `agent mode -resume` (or `agent resume`)

**Join the last scheduled/headless run for THIS repo and continue its work.** 1. Run the SCHEDULE banner (same script as agent mode step 0d3). 2. Locate the latest runner session log for this repo: `ls -t ~/.ai-cli-runner/logs/*-<repo>-task-*.log 2>/dev/null | head -1` — Read it fully; it is the complete transcript of what the scheduled agent did. 3. Cross-check: the task entry in the gateway store (`tasks_list` filtered to this repo, status review/blocked) + `git log test -5` for the runner's commits. 4. Report a JOIN summary: which task ran, when (AEST), its RESULT line, the commits it pushed, and current task status. 5. Then CONTINUE as that agent: you now own the work — review the diff, fix anything off, and await direction (typically `ship it`, which also flips the task review→done via `tasks_update`). 6. If no runner log exists for this repo, say so and fall back to plain `agent mode`. Works identically in every Claude profile (claude / claude-<worker-profile> / claude-<master-profile>) — it reads files + the shared store, not profile-bound session transcripts.

The run streams **live to the dashboard `/fleet` page** (http://localhost:3210/fleet, auto-refresh 4s). Capture the `RUNID=...` tail. 2. **Present** the table and ask the operator for per-repo decisions (e.g. `ship app-a · fix app-b · merge app-c · skip rest`). 3. **Execute each pick DIRECTLY from here** (Option-1 model): `cd` into the repo and run the matching keyword/flow — `ship it` (commit→test→PR→merge, local-ci + admin-merge fallback per policy), fix (diagnose + patch, spawn a focused sub-agent for deep work), `merge` (admin-merge a green PR), test, or `wrap up`. ## `resync`

**Make both memories current — safe at boot AND mid-session.** Runs `./AI/scripts/resync.sh`.

1. **CODE:** `git fetch origin`, with ONE retry on a longer leash (the first fetch at session start is the cold one — DNS, SSH agent, keychain, wifi wake). Then, for the behind-only case, classify every local deviation: a tracked file byte-identical to `origin/<branch>` is a **Dropbox echo** (safe to reset), an untracked file byte-identical to origin's copy is a **collision** (safe to remove so the merge can write), an untracked file with no counterpart on origin is **LOCAL-ONLY** (never touched), and anything else is **genuine local work** → the script STOPS, names the files, and exits 1 rather than guessing. 2. **BRAIN:** delegates to `brain_converge` with a realistic network budget. It is NOT reimplemented here — converge owns the backup ref, the distiller-outputs-only auto-resolve, and the abort-and-escalate on a real atom conflict.
3. **Reports** one honest verdict per half plus the commits/atoms gained. Exit 0 = current, 1 = needs the operator, 2 = usage.

**Never:** `reset --hard`, `clean -fd` (it would take LOCAL-ONLY files), force-push, or auto-merge diverged code.

Flags: `--dry-run` (report the plan, change nothing), `--quiet`, `--code-only`, `--brain-only`.

**WHY IT EXISTS (2026-09-14).** Two real gaps. (a) Nothing synced the code repo except the model — `boot_sync.sh` covers brain + gateway, and the code pull was a prose protocol step; a mid-session re-plug had no mechanism, so 8 code commits + 8 brain atoms from the other Mac only arrived because the operator said so.
