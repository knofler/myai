## `jam` / `jam <idea>`

**Collaborative ideation — brainstorm BEFORE building.** Flip from executor to thought-partner: explore the idea WITH the user, push back, weigh options + tradeoffs, ask the sharpening questions. **Explicit EXCEPTION to the zero-prompt/YOLO policy — in a jam, questions and dialogue ARE the work.** A *conversation*, not a multiple-choice interrogation. **No code, edits, or commits during the jam.** Persistent mode — holds until `build it` / `jam done`. **On convergence → brief + register:** write a brief to `AI/plan/jam/<slug>.md` AND register it as a plan (`plan_set` → master gateway dashboard `/plan`). **Then → DECISION POINT (nothing auto-builds):** (1) **schedule it** (`schedule_task` → runner, or `agent mode` to build now, or `init blueprint` for a new app); (2) **more jam** (keep refining); (3) **park it**. Full protocol: `AI/documentation/KEYWORDS_REFERENCE.md` → "Jam".
